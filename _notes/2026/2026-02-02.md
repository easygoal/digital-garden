# 02-02

在 Unraid 中实现两台设备（Unraid 主机与 Windows 计算机）的网络互通，核心是通过 “路由转发” 让 Windows 计算机通过 Unraid 主机访问局域网内的其他设备（如 NAS 存储、其他电脑）。以下是详细的配置步骤，确保 Windows 能正常访问局域网内的所有资源。

一、核心原理
1. Unraid 主机作为 “网关”：Unraid 主机的 eth0 已通过 DHCP 获取局域网 IP，负责与其他设备通信；eth1 与 Windows 直接连接，作为 Windows 的 “默认网关”。
2. Windows 计算机的网络配置：将 Windows 的 IP 地址设为 Unraid 主机 eth1 的同网段 IP，并将 Unraid 主机 eth1 的 IP 设为 Windows 的默认网关。

二、前提条件
1. 确保 Unraid 主机的 eth0 已正确获取 DHCP 地址（如 192.168.1.100），且能正常访问局域网。
2. 确保 eth1 与 Windows 计算机的网线连接正常（Windows 网卡显示 “已连接”）。
3. 确认 Unraid 主机的 防火墙 已开启转发功能（或允许相关端口通过）。

三、配置步骤
步骤 1：获取 Unraid 主机 eth1 的 IP 地址
1. 登录 Unraid 控制台 → 进入 Network 页面 → 查看 eth1 的当前 IP 地址（若未配置，需先设置）。
2. 示例：假设 eth0 的 IP 为 192.168.1.100，eth1 的 IP 设为 192.168.2.1（与 Windows 同网段，如 192.168.2.x）。

步骤 2：配置 Unraid 主机的网络转发（关键）
1. 登录 Unraid 控制台 → 进入 Settings → Network → Advanced。
2. 在 Routing 部分，确保 “Enable IP forwarding” 已勾选（默认已开启，若未开启需手动勾选）。
3. 保存配置，确保 Unraid 主机能转发 eth1 与 eth0 之间的网络数据包。

步骤 3：配置 Windows 计算机的网络
1. 打开 Windows 计算机 → 进入 控制面板 → 网络和共享中心 → 更改适配器设置。
2. 右键点击 以太网（或当前连接的网卡）→ 属性 → 双击 Internet 协议版本 4 (TCP/IPv4)。
3. 选择 “使用下面的 IP 地址”，填写以下参数：
   - IP 地址：192.168.2.2（与 Unraid eth1 同网段，如 192.168.2.x，且未被其他设备占用）。
   - 子网掩码：255.255.255.0（与 Unraid eth1 子网掩码一致）。
   - 默认网关：192.168.2.1（Unraid eth1 的 IP 地址）。
   - 首选 DNS 服务器：192.168.1.1（或 Unraid eth0 的 IP，用于解析局域网内的设备名称）。
4. 点击 确定，保存配置。

步骤 4：验证网络连通性
1. 在 Windows 计算机上，打开 命令提示符（CMD），执行以下命令：
   - 测试与 Unraid eth1 的连通性：ping 192.168.2.1（若能 ping 通，说明网络连接正常）。
   - 测试访问局域网内的其他设备：ping 192.168.1.100（Unraid eth0 的 IP），或 ping 192.168.1.200（其他局域网设备的 IP）。
2. 若能 ping 通，说明 Windows 已成功通过 Unraid 访问局域网。

四、关键配置说明
1. IP 地址规划：确保 eth1 与 Windows 的 IP 地址在 同一网段（如 192.168.2.x），且未被其他设备占用。
2. 防火墙设置：Unraid 主机的防火墙需允许 “转发” 功能，否则 Windows 无法访问局域网。
3. DNS 配置：确保 Windows 的 DNS 服务器指向 Unraid 主机或局域网内的 DNS 服务器，否则无法解析局域网内的设备名称。

五、常见问题与解决
1. Windows 无法 ping 通 Unraid eth1：
   - 检查网线连接是否正常，或重新插拔网线。
   - 检查 Windows 与 Unraid eth1 的 IP 地址是否在同一网段。
   - 检查 Unraid 主机的防火墙是否允许 eth1 的网络流量。
2. Windows 能 ping 通 Unraid，但无法访问局域网内的其他设备：
   - 检查 Unraid 主机的 路由转发 是否开启（步骤 2）。
   - 检查 Unraid 主机的防火墙是否允许转发 eth1 与 eth0 之间的网络数据包。
   - 检查其他局域网设备的防火墙是否允许来自 192.168.2.x 网段的访问。

六、总结
通过 “Unraid 主机作为网关” + “Windows 配置默认网关” 的方式，即可实现 Windows 计算机通过 Unraid 主机访问局域网内的所有设备。核心是确保 Unraid 主机的 IP 转发 功能开启，且 Windows 的网络配置与 Unraid eth1 在同一网段。
